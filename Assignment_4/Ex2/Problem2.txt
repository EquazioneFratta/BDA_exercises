To run this PySpark script on the IRIS HPC cluster, follow these steps to configure the environment and submit the job:

1. Request an interactive session to install the required dependencies:
   srun -p interactive --pty bash -i

2. Load the necessary Python module:
   module load lang/Python/3.11.5-GCCcore-13.2.0

3. Install the required spatial and data libraries into a local shared directory (e.g., `pylibs`), bypassing the system environment restrictions:
   pip install --target=pylibs shapely pandas apache-sedona==1.9.0 --break-system-packages

4. Ensure that the `launch-spark-submit-sedona.sh` script points to this shared library folder by exporting the PYTHONPATH (e.g., `export PYTHONPATH="/mnt/aiongpfs/users/mfrattarola/Ex4/pylibs:$PYTHONPATH"`).
